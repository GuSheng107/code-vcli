OCR

图片识别翻译扩展

先在本地识别并生成中间文件，用户确认后再翻译。

PYPython

Python 脚本模式

支持独立图片。识别后先生成中间文件并等待确认。

python <skill-dir>/ocr-python/ocr.py --image ./image.png --save

配置时可选择启用；OCR 与翻译依赖使用独立环境。

JSNode.js

Node.js 脚本模式

支持图片、PDF、DOCX、PPTX 和 Markdown 本地图片。

node <skill-dir>/ocr-node/ocr.mjs recognize ./image.png --json

先展示预览和文件路径，确认后进入文件翻译。

TXCLI

TransX CLI 模式

识别图片或文件内图片，生成中间文件，确认后翻译。

transx ocr recognize ./image.png --json

确认后使用 recognition_file 进入文件翻译；未确认不发送。

🔒
本地识别
