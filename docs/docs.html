04
TRANSLATE

transx translate

翻译文本、stdin 或文件。Agent 调用使用 --json。

transx translate [text | --file <path> | --image <path>] --to <lang> [options]

专属参数

参数作用默认值
[text]待翻译文本；省略时从 stdin 读取stdin
-t, --to <lang>目标语言，必填，例如 ZH、EN—
-s, --source <lang>源语言auto
-f, --file <path>翻译 txt/md/csv/log/docx/xlsx/pptx/pdf，与位置文本互斥—
--image <path>识别图片或文件内图片，生成中间文件，确认后翻译—
-o, --output <path>指定译文文件路径源文件目录
--json输出单行 JSON关闭
--timeout <seconds>仅设置本次请求的超时时间，必须为正数20
-h, --help显示 CLI 帮助—

示例

transx translate "Hello world" --to ZH --json

stdin：echo "Hello world" | transx translate --to ZH --json

文件：transx translate --file ./paper.pdf --to ZH --json

图片：transx translate --image ./screenshot.png --to ZH --json

输出：<源文件名>_<目标语言>；PDF 输出 DOCX。文件最多 5 个请求并发执行。

OCR 支持图片、PDF、DOCX、PPTX 和 Markdown；输入 20MB，最多 100 张图片或 100 页 PDF。

COMMAND GROUP

transx ocr

本地识别图片文字，生成可查看的中间文件，确认后再翻译。

transx ocr [enable|status|recognize|remove|help]

transx ocr enable [--yes]

需要 Python 3.10+，下载约 180 MB。模型为 PP-OCRv6 Quality（RapidOCR + OpenVINO），支持中英日等 50 种语言。

参数作用
--yes跳过确认提示
transx ocr enable

transx ocr status [--json]

查看 OCR 扩展安装状态、模型、引擎、平台和验证结果。

transx ocr status --json

transx ocr recognize <path> [--json]

识别图片、PDF 页面、DOCX/PPTX 内嵌图片或 Markdown 本地图片，不翻译。生成 <源文件名>_OCR.md；JSON 返回 recognition_file 和预览。

transx ocr recognize ./image.png --json

transx translate --image 先保存并预览识别结果。仅输入 y/Y 后按文件流程并发翻译；n/N 或 Esc 不发送。

transx ocr remove [--yes]

删除 OCR 扩展，释放磁盘空间。扩展安装在 ~/.transx/features/ocr/，与 CLI 主依赖隔离。

07
COMMAND GROUP

transx history

查看、搜索或清理本地翻译历史。文件记录只保存源文件和译文文件信息。

transx history [list|search|status|clear|help]

transx history [list]

按时间倒序查看记录。省略 list 时行为相同，默认显示 20 条。

参数作用
--limit <n>本次返回条数，默认 20
--offset <n>跳过前 n 条，默认 0
--from <time>仅返回此时间及之后的记录
--to <time>仅返回此时间及之前的记录
--since <Nd>查看最近 N 天，例如 7d；不能与 --from 同用
--json输出适合程序读取的单行 JSON
transx history --limit 50 --offset 100 --json

transx history search <keyword>

不区分英文大小写。文本记录搜索原文和译文，文件记录搜索源文件名和译文文件名。支持与查看命令相同的 --limit、--offset、时间范围和 --json 参数。

transx history search "环境审查" --limit 50 --json

transx history status [--json]

显示历史目录、记录数量、文件总量、最早和最新记录，以及是否需要清理。

transx history clear <mode>

参数作用
--oldest <n>删除最旧的 n 条
--keep <n>只保留最新的 n 条
--before <time>删除指定时间之前的记录
--older-than <Nd>删除早于最近 N 天的记录，例如 30d
--from <time> --to <time>删除指定时间范围内的记录，两项必须同时提供
--all删除全部记录
--yes跳过确认；非交互环境必须提供
--json以 JSON 返回删除条数
transx history clear --older-than 30d --yes

存储与时间

目录~/.transx/history/
文件index.json 与 YYYY-MM-DD.json
提醒超过 30 天或 100 MB，每天最多一次

记录不限制条数，也不会自动删除。时间统一按中国时间处理，格式为 YYYY-MM-DD HH:mm:ss.SSS，不附带时区标记。运行 transx history help 可在终端查看此命令组帮助。

COMMAND GROUP

transx config

查看 URL 模板和完整 API Key，或维护本地配置。

transx config [set-key|reset]

transx config

参数无。输出 URL 模板、完整 API Key、初始化状态和配置文件路径。

transx config set-key [--stdin]

参数作用
--stdin从 stdin 读取新的 API Key；省略时隐藏输入

transx config reset <target>

参数作用
key删除本地 API Key
all重置全部配置（当前等同于删除 Key）

示例

transx config set-key --stdin

环境变量 DLX_API_KEY 会覆盖本地配置，但不会写入配置文件。
