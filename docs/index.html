快速安装 跨平台 · 需 Node.js 22+ 和 Python 3.10+
$ npm i code-vcli

安装完成后重新打开终端即可使用 vcli 命令。Windows 使用 where vcli，macOS/Linux 使用 which vcli 查看路径。
